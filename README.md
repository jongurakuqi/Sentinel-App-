# Sentinel

Simple decentralized chat for people near you — over Bluetooth, no internet required.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173 in two tabs to simulate two nearby devices.

## What it does

1. Pick your name
2. See who's nearby
3. Tap someone to chat, or open a local room for everyone in range

That's it. No accounts, no channels, no commands.

## Note

This web demo uses a local relay to simulate Bluetooth proximity. A native app would use real BLE peer discovery.

When Sentinel is better
Protest / festival / disaster where cell towers are overloaded
Camping, hiking, remote areas
When you don’t want a company logging your chats
When you only care about people right next to you
